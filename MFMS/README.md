**Project Description:**



A C-based Municipal Finance Management System to manage employees, budgets, suppliers, assets and generate financial reports for a municipality.



**System Features:**



\- Employee Management

\- Budget Management

\- Supplier Management

\- Asset Management

\- Financial Reports

\- Main menu integration in main.c



**How to run the system:**



This program can be run on Git bash, CMD , Terminal or VS code depending on user preference or operating system:

gcc main.c employees.c budget.c suppliers.c assets.c reports.c -o MFMS.exe





Running on: Windows (CMD \& Git Bash \& VS Code)

run the following commands:

gcc main.c employees.c budget.c suppliers.c assets.c reports.c -o MFMS.exe

MFMS.exe



Running on: Mac / Linux (terminal)

run the following commands:

gcc main.c employees.c budget.c suppliers.c assets.c reports.c -o MFMS

./MFMS



**Note:** *Check if gcc is installed by running on command line interface: --version, without the gcc installed on the device is not possible to compile the system or program.*
